# Changelog

## 0.1.0

Initial browser-focused release.

- Typed STU device services with WebHID and Web Serial transports.
- Descriptor-driven capabilities, serialized operations, cancellation and disconnect recovery.
- Pen capture, bounded event streams, loss indicators, replay and SVG/PNG/JSON exports.
- Image encoding and full/partial display transfers; persistent image storage and fast recall.
- Startup image/background restoration, boot-logo enablement and typed settings/modes.
- RSA/AES provider, injectable legacy DH adapter, and detached export signatures.
- Typed lifecycle states and deterministic cleanup on cancellation, invalid input and disconnect.
- Immutable recording snapshots and defensive copies of asynchronous operation inputs.
- Getting-started examples, API reference and a macOS serial-to-HID maintenance utility.

See [support and limitations](docs/support-matrix.md). STU-541 TLS, native transports, bundled legacy DH arithmetic and undocumented report layouts are not included.
